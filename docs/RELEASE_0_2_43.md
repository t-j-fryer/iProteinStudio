The app's native UI, headless read/run schema discovery/calls and bundled
client-neutral skill are updated together. MCP clients reconnect after staging;
separately copied skill directories must be refreshed by their owner. The
shared installed runtime is updated only through transactional staging. Existing
jobs retain their immutable code and settings. External viewers stay optional.

Public source is promoted in the release worktree using scoped reviewed patches,
not a merge of the private development/research branch. The preserved paper
baseline remains fixed. The old local research `main` branch is not public main;
public GitHub main follows this release candidate. Publication does not publish
private manuscript datasets, molecules, campaign outputs or model weights.

Structural-diversity clustering, unimplemented specificity/cross-reactive rewards,
cyclic-peptide experiments and workstation orchestration are not silently added
by this release. Enverge hardware throughput and a new GPU campaign are not
qualified here. The source contracts, CPU analysis and packaging checks do not
claim a long interactive soak of a confidential beam-search workspace.

Current distribution remains an ad-hoc signed trusted beta with Sparkle-signed
archives, not Apple Developer ID signed/notarized. Publication/installation
identities and exact checks are recorded in the project Lab Book release entry.
